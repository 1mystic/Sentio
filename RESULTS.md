# Sentio — Eval Results

Comprehensive evaluation results for RAG retrieval, bias classification, and system load capacity.
Auto-generated by `scripts/run_all_evals.py`.

## Running the evals

**From `sentio-api/` with `.env` configured:**

```bash
# RAG + bias classifier evals (default)
python scripts/run_all_evals.py

# With Locust load testing (60s, 25 concurrent users)
python scripts/run_all_evals.py --with-locust https://your-hf-space.hf.space

# Quick mode (skip Cohere reranking)
python scripts/run_all_evals.py --quick

# Bias eval only
python scripts/run_all_evals.py --bias-only

# RAG only (skip bias)
python scripts/run_all_evals.py --skip-bias
```

## Required environment variables

See `.env.example` for full template. Minimum:

- **RAG eval**: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`
- **Bias eval**: `ANTHROPIC_API_KEY`
- **Load testing**: HF Space URL (provided as argument)

Optional:
- `COHERE_API_KEY` (RAG reranking; gracefully degraded without it)
- `OPENROUTER_API_KEY` (fallback LLM provider)
