# Sentio Eval Scripts

Master test runner + individual evaluation scripts for RAG, bias classification, and load testing.

## Quick start

```bash
cd sentio-api

# Configure your .env (copy .env.example)
cp .env.example .env
# Edit .env with your actual API keys

# Run all evals
python scripts/run_all_evals.py

# Check results
cat ../RESULTS.md
```

## Individual scripts

### RAG Retrieval Eval (`eval_rag.py`)
Evaluates the RAG pipeline (pgvector cosine similarity + optional Cohere reranking).

**Metrics:**
- Precision@3 (fraction of top-3 results that match ground truth)
- MRR (reciprocal rank of first relevant result)
- Before/after reranking comparison

**Dataset:** 52 labeled queries across 26 CBT topics

**Requirements:** `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`  
**Optional:** `COHERE_API_KEY` (if absent, skips reranking step)

```bash
python scripts/eval_rag.py                    # Full eval with reranking
python scripts/eval_rag.py --no-rerank        # Skip Cohere step
python scripts/eval_rag.py --out my_results.json
```

**Output:**
- Console summary
- JSON: `scripts/rag_eval_results.json`

### Bias Classifier Eval (`eval_bias.py`)
Evaluates the 15-class cognitive bias classifier against human-labeled journal entries.

**Metrics:**
- Per-class precision, recall, F1
- Macro F1 (average across all classes)
- Exact-set agreement rate (predicted set == expected set)

**Dataset:** 30 entries (2 per class), hand-labeled

**Requirements:** `ANTHROPIC_API_KEY`  
**Cost:** ~$0.006 (30 inference calls × $0.0002/call)

```bash
python scripts/eval_bias.py
python scripts/eval_bias.py --out my_results.json
```

**Output:**
- Console: per-class metrics + summary
- JSON: `scripts/bias_eval_results.json`

### Load Testing (`locustfile.py`)
Benchmark the backend under concurrent load using Locust.

**Metrics:**
- P50 / P95 / P99 response times
- Requests per second
- Error rate

**Requirements:** `locust` package (install: `uv pip install locust`)

```bash
# 25 users, 60 seconds
locust -f scripts/locustfile.py \
  --host https://your-space.hf.space \
  --users 25 --spawn-rate 5 --run-time 60s --headless \
  --csv=scripts/locust_results

# View results
cat scripts/locust_results_stats.csv
```

### QLoRA Training (`sentio-ml/notebooks/sentio_bias_qlora.ipynb`)
Fine-tune Qwen2.5-3B as a distilled bias classifier via LoRA.

**Dataset:** 750 entries (50 per class) generated by Claude Haiku  
**Hardware:** Kaggle T4 (free tier, ~60 min)  
**Metrics:** Student vs teacher per-class F1, agreement rate

This is a **separate Jupyter notebook** — run on Kaggle manually:
1. Open `sentio-ml/notebooks/sentio_bias_qlora.ipynb`
2. Upload to Kaggle
3. Set up dataset (or generate it with Haiku — see notebook)
4. Run all cells (~60–75 min on T4)
5. Compare student vs teacher F1 in evaluation section

## Master runner (`run_all_evals.py`)

Orchestrates RAG + bias evals (and optionally Locust) with nice colored console output and auto-updates `RESULTS.md`.

**Features:**
- ✅ Runs evals sequentially
- ✅ Checks env vars before each eval
- ✅ Catches timeouts / failures gracefully
- ✅ Parses JSON outputs
- ✅ Formats results into `../RESULTS.md`
- ✅ Prints colored summary table

**Usage:**

```bash
# RAG + bias (default)
python scripts/run_all_evals.py

# Quick mode (skip reranking)
python scripts/run_all_evals.py --quick

# With load testing
python scripts/run_all_evals.py --with-locust https://your-space.hf.space

# Bias only
python scripts/run_all_evals.py --bias-only

# Skip bias (RAG only)
python scripts/run_all_evals.py --skip-bias

# All options
python scripts/run_all_evals.py --quick --skip-bias --with-locust https://hf-space.hf.space
```

**Output:**
- Colored console progress + summary
- Updated `../RESULTS.md` with all metrics
- Individual JSON files: `rag_eval_results.json`, `bias_eval_results.json`, etc.

## Environment variables

See `.env.example` for the full template.

**Evals use:**
- `SUPABASE_URL` + `SUPABASE_SERVICE_KEY` — RAG + bias evals
- `ANTHROPIC_API_KEY` — bias classifier (required)
- `COHERE_API_KEY` — RAG reranking (optional)
- `OPENROUTER_API_KEY` — LLM fallback (optional)

**Example `.env`:**
```
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_KEY=eyJhbGc...
ANTHROPIC_API_KEY=sk-ant-...
COHERE_API_KEY=...
```

## Troubleshooting

### `ModuleNotFoundError: dotenv`
```bash
uv pip install python-dotenv
```

### `SUPABASE_URL and SUPABASE_SERVICE_KEY must be set`
- Check `.env` exists and is in `sentio-api/` directory
- Run from `sentio-api/` directory
- Verify values are not empty

### `ANTHROPIC_API_KEY not set`
- Add key to `.env`
- Verify it's a valid Anthropic API key (starts with `sk-ant-`)

### `Cohere reranking skipped`
- This is normal if `COHERE_API_KEY` is absent
- RAG eval still works without it (uses cosine similarity only)
- Set the key to enable reranking metrics

### Locust timeout / connection refused
- Verify HF Space URL is correct and reachable
- Space must be running (might be sleeping on free tier)
- Try: `curl https://your-space.hf.space/health` (if endpoint exists)

### Timeout after 10 minutes
- Individual evals have a 10-minute timeout
- RAG + bias together typically take 5–8 minutes total
- Load testing (60s) should be quick

## Results interpretation

See `../RESULTS.md` for detailed interpretation of each metric.

**Quick notes:**
- RAG Precision@3 > 0.8 is good (Cohere reranking typically improves by 5–10%)
- Bias macro F1 > 0.75 indicates reliable classification
- Load test P95 < 1s under 25 concurrent users is acceptable for free tier
